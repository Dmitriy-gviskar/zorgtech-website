# Zorgtech — Новый сайт

## Дизайн-направление
**Apple (España) Design System** — светлый, воздушный, монохромный. Чередование белого (#ffffff) и светло-серого (#f5f5f7), огромные заголовки с минусовым трекингом, ни одной тени, ни одного разделителя. Акцентный синий (#0071e3) — только на интерактиве.

## Структура проекта

```
zorgtech-new/
├── index.html          # Концепт-лендинг (Apple-стиль)
├── data/               # Данные с текущего сайта
│   ├── products.txt    # Полный каталог: 82 продукта
│   ├── catalog.html    # Главная страница каталога
│   ├── catalog-*.html  # HTML каждой категории
│   ├── solutions.html  # Готовые решения
│   ├── projects.html   # Реализованные проекты
│   ├── about.html      # О компании
│   └── contacts.html   # Контакты
├── img/                # 79 изображений продуктов и проектов
├── fetch.sh            # Скрипт загрузки страниц
├── extract.py          # Скрипт извлечения данных
└── dl_images.sh        # Скрипт загрузки изображений
```
